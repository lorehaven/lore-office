A PDF reader with page tools. The page is drawn from the file's own content (text, paths, images), with a text layer for selecting and searching.

## Reading

Page thumbnails at the side, zoom, search, the document's outline and links, dark pages. File ▸ *Open…* reads a PDF (also by dropping it), and *Open in the browser's viewer* hands the file to the browser.

## Changing

The Annotate tab marks text (highlight, underline, strike-out), adds notes and typed words. The Edit pages tab turns a page a quarter turn either way, moves it earlier or later, deletes it, adds the pages of another PDF after this one, saves a copy of the file with the changes, or saves the page shown as a file of its own. Changes can be undone. The original file on your computer is not touched.

## Cloud

A PDF opened from the cloud is saved back to the cloud as its own bytes; with no file open there is nothing to save.
