The launcher and four apps. Each runs in the browser, keeps what you are working on in the browser's storage, and opens and saves files on your computer. With the cloud on, each also has File ▸ *Cloud…*; see [Sharing](../guides/sharing.md).

| App | For | Files |
|---|---|---|
| [docs](docs.md) | text | opens `.docx`, `.txt`, `.md`; saves `.docx`, `.html`, `.md`, `.txt`, PDF |
| [sheets](sheets.md) | spreadsheets | opens `.xlsx`, `.ods`, `.xls`, `.csv`, `.tsv`; saves `.xlsx`, `.ods`, `.csv`, `.tsv`, PDF |
| [notes](notes.md) | Markdown notes and slide decks | opens `.md`, `.txt`; saves `.md`, a vault `.zip`, `.html`, slide show `.html`, slides as PDF |
| [pdf](pdf.md) | reading and changing PDF files | opens `.pdf` |

The launcher (`/`) shows one tile for each app, with its icon.

## What they share

* **The ribbon**: File and the tabs on the first line, with the home link (the house icon) to the launcher, the app's name, the document's name (click it to rename), the status text, Cloud, the language picker and the theme menu; the tools of the chosen tab on the second line. Tools are icons with tooltips where a drawing says it better than a word.
* **Look and language**: [Theme and language](../guides/theme-and-language.md).
* **Storage in the browser**: the document is kept after each change and restored on the next visit.
* **Dropping files**: a file dropped on the page is opened.
